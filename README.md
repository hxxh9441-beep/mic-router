# 🎙️ مكبّر الصوت — حوّل جوالك إلى مايكروفون مع فلاتر وتسجيل

تطبيق ويب صفحة واحدة يحوّل جهازك إلى **مكبّر صوت حي**: يلتقط الميكروفون ويرسله مباشرة إلى السماعات (سلكية أو بلوتوث) مع فلاتر لحظية وتسجيل اختياري — **PWA كاملة** تعمل كتطبيق مستقل من شاشتك الرئيسية.

## ✨ المميزات

- 🎙️ **توجيه مباشر**: ميكروفون → سماعات بدون تخزين وسيط (تأخير منخفض `latencyHint: 'interactive'`)
- 🎛️ **3 فلاتر حية**: قطع الضوضاء المنخفضة (High-Pass 20–500Hz) · الحساسية (Gain 0–2x) · صدى قابل للضبط
- 🎚️ **تحكم دقيق**: كل فلتر عنده حقل نسبة قابل للكتابة + أزرار ±5% + قيم سريعة [25|50|75|100]
- 🔴 **تسجيل الجلسة**: MediaRecorder يلتقط الصوت **بعد** الفلاتر (اللي تسمعه هو اللي يتسجل) + مؤقت حي
- ⏹️ **إيقاف ذكي**: حفظ تلقائي للتسجيل حتى لو أوقفت الجلسة أو عطّلت التسجيل أثناء العمل
- 🔇 **كتم المخرج**: سجّل بدون ما تسمع نفسك — السماعات تصمت والتسجيل يستمر
- 💾 **تنزيل فوري**: زر «تنزيل التسجيل» بعد كل تسجيل (webm / m4a / ogg حسب المتصفح)
- 📊 **فيجوالايزر** حي (طيف الترددات) عبر AnalyserNode
- 📱 **PWA كاملة**: تثبيت من الشاشة الرئيسية (Android + iPhone) + تشغيل أوفلاين

## 🎛️ سلسلة المعالجة

```
الميكروفون (getUserMedia — echoCancellation/noiseSuppression/autoGainControl: false)
  → High-Pass Filter (20–500Hz)      ← قص الهمهمة المنخفضة
  → Gain (0–2x)                      ← الحساسية
  → [ Master Gain ]
       ├─ → مراقبة المخرج (كتم اختياري) → السماعات    ← متصلة دائماً
       ├─ → حلقة الصدى: wet → Delay (0–1s) → feedback → مراقبة المخرج
       └─ → MediaStreamDestination   ← التسجيل (جاف + رطب) — لا يتأثر بالكتم
            └─ → MediaRecorder → Blob → مشغّل + تنزيل
```

- **مسار جاف مباشر**: `الحساسية ← مراقبة ← السماعات` متصل **دائماً** حتى لو كل المؤثرات 0%.
- **كتم المخرج**: خيار «كتم المخرج» يسكّت السماعات فقط (للتسجيل الصامت) والتسجيل يستمر.
- **استئناف مبكر**: `resume()` يُستدعى فور الضغط — قبل طلب الميكروفون — ضمن إيماءة المستخدم.
- **تحصين القيم**: كل الفلاتر ترفض NaN/النصوص وتُقلم لحدودها (الحساسية لا تنزل عن 1.0 الافتراضية).

## 📱 توافق الجوال (iOS Safari + Android)

مشكلة معروفة على الجوال: الميكروفون يلتقط (الأيقونة الخضراء) لكن لا يخرج صوت من السماعات.
السبب الموثق: **Safari يعلّق الـ AudioContext أثناء نافذة إذن الميكروفون** ([SAFARI_WEBAUIO_QUIRKS](https://github.com/msitarzewski/openstudio/blob/main/docs/SAFARI_WEBAUIO_QUIRKS.md) ·
[WebKit bug 261554](https://bugs.webkit.org/show_bug.cgi?id=261554))، والعقد المبنية في سياق معلّق
لا تعالج الصوت إطلاقاً. المعالجة في هذا المشروع:

1. **🔓 فتح iOS (`iosAudioUnlock`)**: سياق مؤقت يُستأنف في **أول سطر** من النقرة — يقلب عداد
   «has succeeded» عند iOS فيقبل كل الاستئنافات اللاحقة (حتى بعد نافذة الإذن).
2. **🔑 استئناف حاسم بعد الإذن**: `start()` يستدعي `resume()` **بعد** `getUserMedia` و**قبل** بناء
   العقد — فالسياق يعمل قبل إنشاء أي عقدة (العقد في سياق معلّق = صمت).
3. **⏱️ حد زمني آمن**: `_resumeCtx()` يتسابق مع مؤقت 1200ms — لا يعلّق `start()` أبداً إذا رفضت
   السياسة الاستئناف.
4. **♻️ استئناف مستمر (keep-alive)**: أي نقرة/لمسة أو عودة للتبويب من الخلفية تعيد محاولة
   الاستئناف تلقائياً (iOS يعيد التعليق أحياناً عند عودة التبويب).

## 📱 PWA (تثبيت + أوفلاين)

- `manifest.webmanifest` — الاسم «مكبّر الصوت»، وضع مستقل، أيقونات 192/512.
- `sw.js` — شبكة أولاً للصفحة (التحديثات تصل فوراً) + كاش أولاً للأصول.
- شريط تثبيت سفلي: **Android/Chrome** (زر «تثبيت» عبر `beforeinstallprompt`) و**iPhone** (تلميح «إضافة إلى الشاشة الرئيسية»).
- إهمال المستخدم للشريط يُحفظ ولا يظهر مرة أخرى.

## 🛠️ التقنية

| الطبقة | التقنية |
|---|---|
| البناء | ملفات ثابتة بدون خطوات بناء — جاهزة للنشر المباشر |
| التنسيق | **Tailwind CSS** (CDN) + وضع داكن + RTL عربي + متجاوب |
| الصوت | Web Audio API (AudioNodes) + getUserMedia |
| التسجيل | MediaRecorder (opus/webm · m4a · ogg حسب المتصفح) |
| الاختبارات | Node.js `node:test` — تستخرج المحرك من index.html وتحاكي Web Audio |
