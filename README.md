# 🎙️ موجّه الصوت — اربط ميكروفونك بسماعتك مباشرة

تطبيق ويب صفحة واحدة لتحويل جهازك إلى **مكبّر صوت حي**: يلتقط الميكروفون ويرسل الصوت مباشرة إلى السماعات (سلكية أو بلوتوث) مع مؤثرات لحظية وتسجيل اختياري — **يعمل بالكامل في متصفحك، صوتك لا يغادر جهازك أبداً**.

## ✨ المميزات

- 🎙️ **توجيه مباشر**: ميكروفون → سماعات بدون تخزين وسيط (تأخير منخفض `latencyHint: 'interactive'`)
- 🔇 **بدون صدى (Feedback)**: سلسلة الميكروفون لا تتصل أبداً بالسماعات إلا عند الضغط على «تشغيل» — ومع ذلك التسجيل يشمل كل المؤثرات
- 🎛️ **3 مؤثرات حية**: قطع الضوضاء المنخفضة (High-Pass 20–500Hz) · حساسية الميكروفون (Gain 0–2x) · صدى قابل للضبط (تأخير 0–1s + تغذية راجعة)
- 🔴 **تسجيل الجلسة**: MediaRecorder يلتقط الصوت **بعد** المؤثرات (اللي تسمعه هو اللي يتسجل) بصيغة WEBM/M4A/OGG حسب المتصفح + مؤقت حي
- ⏹️ **إيقاف ذكي**: حفظ تلقائي للتسجيل حتى لو أوقفت الجلسة أو عطّلت التسجيل أثناء العمل
- 💾 **تنزيل فوري**: زر «تنزيل التسجيل» بعد كل تسجيل
- 📊 **فيجوالايزر** حي (طيف الترددات) عبر AnalyserNode
- 🛡️ **100% Client-Side**: لا تُرفع أي بيانات لأي خادم

## 🎛️ سلسلة المعالجة

```
الميكروفون (getUserMedia — echoCancellation/noiseSuppression/autoGainControl: false)
  → High-Pass Filter (20–500Hz)      ← قص الهمهمة المنخفضة
  → Gain (0–2x)                      ← حساسية الميكروفون
  → [ Master Gain ]
       ├─ → السماعات (فقط عند «تشغيل») + Analyser (الفيجوالايزر)
       └─ → حلقة الصدى: wet → Delay (0–1s) → feedback → رطب/جاف
  → MediaStreamDestination           ← نقطة الالتقاط للتسجيل (بعد المؤثرات)
       └─ → MediaRecorder → Blob → مشغّل + تنزيل
```

## 🛠️ التقنية

| الطبقة | التقنية |
|---|---|
| البناء | ملف واحد `index.html` (بدون خطوات بناء — جاهز للنشر المباشر) |
| التنسيق | **Tailwind CSS** (CDN) + وضع داكن + RTL عربي + متجاوب |
| الصوت | Web Audio API (AudioNodes) + getUserMedia |
| التسجيل | MediaRecorder (opus/webm · m4a · ogg حسب المتصفح) |
| الاختبارات | Node.js `node:test` — تستخرج المحرك من index.html وتحاكي Web Audio |

## 🚀 التشغيل المحلي

افتح `index.html` مباشرة في المتصفح (أو):

```bash
cd "mic-router - GitHub"
python3 -m http.server 8080     # ثم افتح http://localhost:8080
node test/mic-router.test.mjs   # تشغيل اختبارات الوحدة (18/18)
```

## 🌐 النشر على GitHub Pages

ملف واحد ثابت — لا يحتاج بناء:

1. ارفع المشروع إلى مستودع GitHub (`git init && git add . && git commit -m "init" && git push`).
2. من إعدادات المستودع: **Settings → Pages → Source: Deploy from a branch → main / root**.
3. الموقع النهائي: `https://<username>.github.io/mic-router/`
